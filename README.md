# Kenny's Sandboxels Mods

Custom mods for the **Sandboxels browser version**.

## Hidden Element Unlocker

- File: `unlock_all_hidden.js`
- Waits for Sandboxels to finish loading, then removes the hidden flag from elements.
- Based on the loading approach used by Sandboxels' own `unhide.js` mod.

Raw mod URL:

`https://raw.githubusercontent.com/kennymonster454/kennys-mod-list-sandboxles-/main/unlock_all_hidden.js`

## Steam Generator

- File: `steam_power.js`
- Adds a Steam Generator to the Machines category.
- Steam or radioactive steam touching it is consumed and triggers Sandboxels' native electrical charge.

Raw mod URL:

`https://raw.githubusercontent.com/kennymonster454/kennys-mod-list-sandboxles-/main/steam_power.js`

Add each raw URL through Sandboxels' Mods menu. These updates are based on the official mod code patterns, but still need to be tested in-game.
