# Kenny's Sandboxels Mods

Custom mods for the **Sandboxels browser version**.

## Hidden Element Unlocker

- File: `unlock_all_hidden.js`
- Reveals elements marked as hidden so they appear in the element menu.
- This is a cheat/unlock mod; it does not create new elements.

Raw mod URL:

`https://raw.githubusercontent.com/kennymonster454/kennys-mod-list-sandboxles-/main/unlock_all_hidden.js`

Add that URL through Sandboxels' Mods menu. Reload the game if the element menu does not refresh.

## Steam Power

- File: `steam_power.js`
- Target version: Sandboxels 1.16.1 (November 21, 2026 — OtA Hotfix)
- Adds a Steam Generator in the Machines category.
- The generator consumes steam touching it and activates Sandboxels' native electrical charge system. Conductive metal can carry that charge.

Raw mod URL:

`https://raw.githubusercontent.com/kennymonster454/kennys-mod-list-sandboxles-/main/steam_power.js`
