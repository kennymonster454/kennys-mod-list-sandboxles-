# Kenny's Sandboxels Mods

Custom mods for the **Sandboxels browser version**.

## Steam Power

- File: `steam_power.js`
- Target version: Sandboxels 1.16.1 (November 21, 2026 — OtA Hotfix)
- Adds a Steam Generator in the Machines category.
- The generator consumes steam touching it and activates Sandboxels' native electrical charge system. Conductive metal can carry that charge.

### Load it in Sandboxels

Use the raw file URL:

`https://raw.githubusercontent.com/kennymonster454/kennys-mod-list-sandboxles-/main/steam_power.js`

Add that URL through Sandboxels' Mods menu.
